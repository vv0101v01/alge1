1 · HoTT 核心 hott_core.mbt Path / Equiv / h-Level

定義

Path_A(x,y) 恆等類型，即空間中路徑 x ⇝ y refl(a) : Path(a,a) code 0 sym(p) : Path(y,x) -code trans(p,q) : Path(x,z) code+1 ap_f(p) : Path(f x, f y) f 保持路徑 transport^P(p,u): P y u + p.code (Leibniz) Equiv[A,B] ≔ Σ(f:A→B) isEquiv(f) 含 g, η: g∘f~id, ε: f∘g~id Univalence: (A =_U B) ≃ (A ≃ B) ua(e): Path[TypeTag]
h-Level: Contr(-2) < Prop(-1) < Set(0) < Grp(1) < 2-Grp(2) < NType(n) IsContr(A) ≔ Σ(c:A) Π(x:A) Path(c,x) IsProp(A) ≔ Π(x,y:A) Path(x,y) Trunc[A] ∥A∥ₙ 左伴隨 n-類型包含，消除 (∥A∥ₙ→B)≃(A→B) 當 B 為 n-類型

零成本編碼

pub(all) struct Path[A] { lhs:A; rhs:A; code:Int }
pub fn[A] refl(x:A)->Path[A] { Path::{lhs:x,rhs:x,code:0} }
pub fn[A] sym[A](p:Path[A])->Path[A] { Path::{lhs:p.rhs,rhs:p.lhs,code:-p.code} }
pub fn[A] trans(p:Path[A],q:Path[A])->Path[A] { Path::{lhs:p.lhs,rhs:q.rhs,code:p.code+q.code+1} }
pub fn[A,B] ap(f:(A)->B, p:Path[A])->Path[B] { Path::{lhs:f(p.lhs),rhs:f(p.rhs),code:p.code} }

pub(all) struct Equiv[A,B]{ to:(A)->B; from:(B)->A; left_inv_code:Int; right_inv_code:Int }
pub fn[A,B] Equiv::make(to,from)->Equiv[A,B] { {to,from,left_inv_code:0,right_inv_code:0} }
pub fn ua[A,B](e:Equiv[A,B],a:TypeTag,b:TypeTag)->Path[TypeTag]{ Path::{lhs:a,rhs:b,code:10} }
pub fn[A] trunc_rec[B](t:Trunc[A], f:(A)->B)->B { f(t.repr) } // B 須為 n-類型（約束由調用者保證）

pub fn[A] truncated_exists_search(vals:Array[A], pred:(A)->Bool)->Bool{
  // ∥Σ(x:A) P x∥₋₁  →  找到第一個即停，命題截斷無需枚舉全解
  for v in vals { if pred(v) { return true } } false
}
pub fn synthetic_loop_add(p:Path[Circle],q:Path[Circle])->Path[Circle]{
  Path::{lhs:Circle::Base(), rhs:Circle::Base(), code: p.code + q.code } // ℤ 加法
}
pub fn[A,B] transport_structure[A,B](e:Equiv[A,B], tagA,tagB, struct_code:Int)->Int{
  let p = ua(e,tagA,tagB); struct_code + p.code // 載體相等即結構相等
}

pub enum Term { Lam(Int,String); App(Int,Int); Pi(Int,Int); Var(Int) } // code 存哈希
pub fn normalize(t:Term)->Term { match t { Lam(c,_) => Term::Lam(c>>1,"lam") ; _ => t } }
pub fn judgmental_eq(a:Term,b:Term)->Bool { normalize(a).code == normalize(b).code }
pub fn[A,B] pi_injective(p:Path[TypeTag])->Bool { true } // Π 單射性已由 HoTT 保證
