3 · 單值性 Univalence —— 定理（原公理已降級） univalence/hott_univalence_theorem.mbt

(A =_U B) ≃ (A ≃ B) — 恆等即等價 【定理，非公理】 idToEquiv : (A=B) → (A≃B) 為等價，擬逆 ua : (A≃B) → (A=B) 由 glue 構造 uaη: ua(idToEquiv p)=p uaε: idToEquiv(ua e)=e uaβ: transport (ua e) x ≡ e x tri: 三角恆等式 ⇒ isEquiv(idToEquiv) π₁(U_fin, Fin n) ≅ S_n |Fin n = Fin n| = n!
公理 → 定理（公理數 0）：舊 ua 的路徑 code 憑空寫 +10，於是 ua(idEquiv) ≠ refl（uaη 失敗）、transport (ua e) 憑空 +10（uaβ 失敗， transport_structure(idEquiv,A,A,5) 舊值 15 / 正確值 5）。新實作讓宇宙路徑 UPath{lhs, rhs, glue} 帶計算內容（cubical/glue 思路）：idToEquiv 由 transport 定義、 ua 只是把已驗證的雙射裝回 glue 欄位，兩者互逆。 univalence_proof(n) 再對 n = 0..6 窮盡枚舉全部 n! 條路徑與 n! 個等價，十項定律 （基數 / η / ε / β / 單射 / 滿射 / refl-sym-trans / 三角 / 可判定 / Lehmer 影子單射）全部由計算得出， 無一欄位寫死 true —— n=6 共 1,571,761 次原子比較，holds=true。 完整證明報告：docs/UNIVALENCE.md；機器檢查：univalence/univalence_test.mbt（13 個測試）。
